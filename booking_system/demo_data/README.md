# Demo Data Pack (Group Version)

## Files
- `groups_demo.csv`: 8 groups with credentials and member lists.
- `schedule_round1.txt`: first-round schedule windows.
- `schedule_round2.txt`: additional windows for round 2.

## Group CSV format
`group_code,group_name,contact_email,password,members`

`members` uses `;` separator.

## Schedule format
Each line:
`YYYY-MM-DD,HH:MM,HH:MM`
